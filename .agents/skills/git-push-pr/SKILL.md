# Git Push PR Skill (Orchestrator)

このスキルは、プロジェクトのバリデーション（テスト実行）を行った後、グローバルスキルの `git-commit` および `github-pr` を順次呼び出して、変更のコミット、プッシュ、およびプルリクエスト作成までのワークフローを一気通貫で実行します。

## 🚨 制約事項 (Constraints)
- **テストの必須実行**: コミットおよびプッシュを行う前に、必ずプロジェクトの全テストと型チェックがパスすることを確認してください。テストが失敗した場合は、その時点で処理を中断し、ユーザーにエラーを報告してください。
- **グローバルスキルの活用**: コミット処理にはグローバルスキルの `git-commit` を、プッシュとPR作成には `github-pr` をそれぞれ読み込んで実行してください。重複したロジックをここで再定義しないでください（UNIX哲学の遵守）。

## 🛠️ 実行手順 (Execution Steps)

### 1. プロジェクトの検証（テスト）
1. 以下のコマンドを実行し、プロジェクトのビルド、型チェック、およびテストがすべて成功することを確認します。
   ```bash
   npm run check && npm run test && cargo test --manifest-path src-tauri/Cargo.toml
   ```
2. エラーが発生した場合は、速やかに処理を中断し、ユーザーにログを提示して修正を求めてください。

### 2. コミット処理（`git-commit` スキルの起動）
1. テストが成功したら、グローバルスキル `git-commit` をロードし、その手順に従って変更のステージングとコミットを実行します。
2. ユーザーからのコミットメッセージの承認と、コミットの完了を確認します。

### 3. プッシュ＆PR作成処理（`github-pr` スキルの起動）
1. コミットが完了したら、グローバルスキル `github-pr` をロードし、その手順に従ってリモートへのプッシュおよびプルリクエストの作成を実行します。
2. 作成されたPRのURLを最終報告としてユーザーに提示します。
